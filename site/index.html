02 / UNDER THE SURFACE

One command.
One disposable Linux VM.

macOS supplies the virtualization layer. Rift assembles a read-only image root, adds a temporary writable layer, then shuts down the guest when the command finishes.

03 / WHAT WORKS TODAY

A real runtime,
with its edges in view.

A

OCI, direct from registries

ARM64 manifest selection, Bearer auth, verified blobs and local image storage.

B

Linux process execution

Entrypoint, command, environment, working directory, user and groups; private PID and mount namespaces.

C

Networking and shares

Outbound networking, one localhost TCP port, and explicit read-only or writable file and directory volumes.

D

Detached lifecycle

Run, list containers, read logs, stop or kill a container, and reclaim unreferenced image data.

!

Early-stage software. OCI ownership, PAX metadata, extended attributes, special files and broader process isolation are still incomplete. Rift is not a Docker replacement yet.

04 / TRY THE SOURCE BUILD

Make the binary
on your Mac.

Rift is written in Zig. A public Developer ID signed and notarized download is not available yet, so the supported path is a local build.

TERMINAL
brew install zig
git clone https://github.com/OthmaneBlial/Rift.git
cd Rift
zig build -Doptimize=ReleaseSafe
mkdir -p "$HOME/.local/bin"
install -m 755 zig-out/bin/rift "$HOME/.local/bin/rift"
